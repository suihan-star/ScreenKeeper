# 屏幕良伴使用指南

适用于当前首版功能。快速入口见 [项目 README](../README.md)，开发与目录约定见 [开发说明](development.md)。

## 本地开发与试用

构建需要 Windows 和 .NET 8 SDK；解决方案及源码目录仍沿用 `OLED-Sleeper` 名称，应用输出为 `ScreenKeeper.exe`。

```powershell
dotnet restore OLED-Sleeper.sln
dotnet build OLED-Sleeper.sln -c Release --no-restore
dotnet test OLED-Sleeper.sln -c Release --no-build
dotnet format OLED-Sleeper.sln --verify-no-changes --no-restore
```

本地生成无需另装 .NET 的 x64 便携版（首次构建需要联网还原运行时依赖）：

```powershell
dotnet publish OLED-Sleeper/OLED-Sleeper.csproj -c Release -r win-x64 --self-contained true -p:Portable=true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -o artifacts/portable/ScreenKeeper
```

运行输出目录中的 `ScreenKeeper.exe`。首次启动默认不启用任何屏幕规则；在“屏幕休息”或“隐私保护”选择屏幕，开启对应功能、调整规则后保存。两项分别开启与保存。窗口关闭按钮隐藏到托盘，托盘菜单可打开设置、按屏幕暂缓、切换开机启动或退出。

屏幕休息、隐私保护和色温页优先显示显示器型号；同型号追加系统显示编号（如 `Q27P10 · 1`、`Q27P10 · 2`），无法读取型号时显示“显示器 N”。名称只用于识别，不改变已保存的屏幕设置。

- 安装版/普通构建：设置及状态存于 `%APPDATA%\ScreenKeeper`，日志位于其 `Logs` 子目录。
- 便携版：设置及状态存于程序旁的 `Data\ScreenKeeper`，请放在可写入目录，并在移动程序时保留该目录。
- 不读取、复制或清理 OLED Sleeper 配置；安装脚本使用独立 AppId、安装目录与启动项，重装保留 ScreenKeeper 自己的配置。
- 窗口右上角“语言 / Language”可即时切换简体中文和英文；偏好保存在独立数据根目录的 `ui-preferences.json`。切换不丢失显示器草稿，重新启动后恢复上次保存的语言。
- 静绿样式与双语实施、验证和限制见 [003 设计](tasks/003-calm-ui-design.md) 与 [003 计划](tasks/003-calm-ui-plan.md)。默认深绿，顶部语言旁可切换雾白绿，两主题不改变业务草稿。
- 两个程序同时管理同一显示器仍可能争用亮度或遮罩，试用时应只启用其中一个程序的管理功能。
- 产品图标采用 A+「叠屏静夜」的 A「雾绿轮廓」。运行中的任务栏按钮与托盘统一跟随 Windows 系统主题：深色任务栏用浅绿，浅色任务栏用深绿；窗口内部标题栏图标继续跟随应用主题。源文件及重新生成方式见 [图标资源说明](../OLED-Sleeper/Assets/README.md)，实施与验证见 [004 计划](tasks/004-tray-icon-plan.md)。
- 安装向导仍为英文；安装脚本此前已用 Inno Setup 6.7.3 编译验证；运行 `./build.ps1 -SkipPortable` 可仅生成安装包。真实硬件和安装/卸载验收情况见第一阶段计划。
- 根 `LICENSE` 随构建和 publish 输出复制；完整第三方许可清单需在正式发行前补齐。

版本与构建方式见 [开发说明](development.md)。本仓库提交不等于创建了正式发行版；硬件验收边界以各任务记录为准。

## 设置布局 v5 与每屏隐私保护

左侧“屏幕休息”和“隐私保护”为独立菜单，共用当前屏幕选择。在“隐私保护”开启本屏隐私开关，选择隐私幕、回到桌面或指定应用，设置等待时长后保存。关闭开关会收起设置，保留上次方式与参数，保存后停用；重启后再次开启仍可恢复上次方式。旧设置保留原来的实际开启状态，新功能不会自行启用。默认等待 30 秒，支持秒/分钟/小时，上限 24 小时。

- **隐私幕**：本屏无实际操作后显示默认山林背景，先完全遮挡，再渐显图片。未开启使用免打扰时，其他屏幕操作与鼠标静止不重置本屏计时。保护后鼠标经过或键盘操作只会唤亮，点击“进入此屏幕”才显示原内容；没有密码认证。
- **使用时不打扰**：开启后，自选“鼠标停留在本屏”“前台窗口在本屏”“电脑有键盘或鼠标输入”；满足任一勾选条件就延后自动保护，条件结束后重新等待。初始候选为前两项，升级不会自动打开免打扰。已有隐私幕不会自动解除，手动立即保护仍可使用。
- **回到桌面**：先遮挡，再最小化完全位于该屏的应用窗口；不关闭应用、不影响其他屏幕，也不会自动还原原窗口。跨屏窗口、无法最小化或验证失败会保留隐私幕。
- **与休息搭配**：在“屏幕休息”选择遮黑或调暗，关闭休息开关也能单独保护内容。若休息时间先到，先保护再休息；使用免打扰命中时同时延后休息，避免休息前保护打断使用。执行前再次检查活动，过期请求不再遮黑或调暗。
- **暂缓与恢复**：两页各自就地打开“暂缓休息”或“暂缓保护”，默认只影响当前项；明确勾选后可一起暂缓，两项须均已保存开启。可选 15／30／60 分钟或输入分钟／小时，范围 1 分钟至 24 小时；隐私默认时长可在“更多设置”修改。暂停本次计时不保存草稿、不唤醒已休息屏幕、不解除现有幕布，保存规则不重置有效截止；到期或主动恢复后重新等待。本次暂缓仅在当前程序会话有效。
- **托盘快捷操作**：可立即保护所有已保存启用的屏幕，或通过“按屏幕暂缓”打开所选屏幕设置和暂缓弹窗；两项联合暂缓时提供“恢复两项”。
- **退出与恢复**：确认退出后先关闭本软件的遮黑和隐私幕，再恢复硬件状态；如果原色恢复未完成，会显示可从任务栏找到的提示并保留恢复记录。遮黑请求在真正显示前复核活动，避免唤醒后被迟到的旧请求再次盖黑。排查和回归证据见 [011 计划](tasks/011-blackout-recovery-plan.md)，实机故障不能仅凭模拟测试认定完全解决。

- **指定应用**：选择正在运行的具体窗口或本地 `.exe`；默认不启动程序、不跨屏移动。可分别允许启动/移动；程序未运行、多窗口不明确、其他窗口无法隐藏或覆盖检查失败时保留幕布。原窗口不自动还原。应用内容不会清空，请选择可以公开展示的窗口。
- **布局**：顶部状态卡固定显示已保存规则的运行状态，提供本屏暂缓和立即保护；正文按“何时保护／如何保护”分区，底部提供应用到其他屏幕。隐私幕只显示背景预览与摘要，点击“调整外观”统一设置背景与图片；默认暂缓在直接展示的“更多设置”中，上下以横线分隔。指定应用的启动／跨屏许可和说明直接显示在主页面“更多设置”上方，以横线与应用选择区域分开；修改后须保存隐私保护。应用选择弹窗只选窗口／程序，取消不改草稿。
- **幕布外观**：默认山林、纯色或 1–12 张自定义图片（每张 10 MB 内），图片管理弹窗内可设置铺满/完整显示及秒/分钟轮播间隔，只有多图时显示轮播选项。幕布只显示“进入此屏幕”按钮。PNG/JPEG 直接导入；WebP 需要系统解码器。图片以独立副本保存于产品数据根目录的 `PrivacyImages`，移除原图不影响已导入图；放弃/移除设置不自动删除磁盘副本。
- **保存与跨屏应用**：保存／放弃只处理当前模块的全部屏幕，保留另一模块草稿。复制当前模块设置到全部或指定屏幕，形成可放弃的草稿，保留目标启用状态；休息设置不支持调暗时改用遮黑。同一应用窗口不能分配给多个启用屏幕。
- **通用设置**：左下角可调整语言和开机启动；语言入口、保存/放弃操作栏保持固定可见。标题栏支持系统拖动、最大化/还原及对应图标。

该功能用于减少旁人意外看到内容，不替代 Windows 锁屏。系统通知、任务切换、置顶应用、安全桌面和程序退出/崩溃等仍可能露出内容；“回到桌面”也不会持续阻止应用重新弹出窗口。离开电脑且需要访问控制时请使用 `Win+L`。

实现与验证见 [005 设计](tasks/005-monitor-privacy-design.md) 和 [005 计划](tasks/005-monitor-privacy-plan.md)。布局 v3 与扩展功能见 [006 设计](tasks/006-settings-layout-design.md) 和 [006 计划及验证记录](tasks/006-settings-layout-plan.md)。真实多屏输入、窗口最小化、DDC/CI 和混合 DPI 仍需实机验收。

## 健康提醒与色温开发模块

左侧健康提醒与色温入口独立于每屏休息和隐私开关。底栏保存当前模块；切换页面保留其他模块草稿，关闭到托盘也保留，退出时列出未保存模块。

健康提醒的“提醒节奏”直接展示时长、减少打扰和更多设置，分区之间用横线区分，无需展开“更多设置”。

- **健康提醒**默认关闭。首次启用建议工作 50 分钟、休息 5 分钟、稍后 5 分钟，可编辑。默认山林静景（与隐私幕共用）用 8 秒渐显至 30%，可选深绿流动雾光或简洁卡片，导入自定义图片、调整渐显/覆盖/动态。覆盖程度支持 10–100%，100% 完全盖住背景，动态可关闭或调整强度。到期轻提示不抢焦点，背景不阻挡操作；主动开始后默认进入山林图片休息画面并倒计时，也可选择静夜微动；已保存的样式不自动改写，可收起或提前结束。尊重系统减少动画设置。自动提醒遵循全屏免打扰；手动“预览当前外观”使用草稿，可在全屏下预览和切换示例休息画面，不改变真实工作周期。
- 隐私保护、遮黑、锁屏优先于健康画面；不唤醒其他屏幕。无输入不代表确实休息。托盘可开始休息、暂停 1 小时及恢复，悬停显示倒计时。自定义提醒图片独立保存在 HealthImages，缺失时使用内置山林背景；两模块仍各自保存自定义图片偏好。
- **色温**保留「作息与色温」「屏幕与验证」两个页签。在作息页选择已验证屏幕，打开「开启此屏幕色温调节」，分别设置本屏的工作／休息时间和色温；各屏互相独立。两时段均采用「保持原色／自定义色温」双选项，3500–6500K 滑杆向左更暖、向右更接近中性。切换原色保留最近有效自定义值，保存失败保留原始输入。开关下两个色块显示已保存的工作／休息目标，草稿和试调不会修改摘要。切屏保留草稿，保存／放弃作用于本模块全部屏幕。
- **即时试调**：在参数上方展开左侧「在此屏幕试调」，点击工作／休息试调按钮后，拖动滑杆感受变化，无需再次选屏。停止调整 15 秒后恢复该屏已保存策略，其他屏幕保持各自策略；按住「对比原色」查看接管前基线。切屏、页签、模式／原色选项、离开页面、最小化、关闭窗口或保存／放弃结束试调，数值仍保留。编辑和试调不会自动保存。
- 首次使用在「屏幕与验证」点击「开始验证」：先退出其他调色工具和自定义校色，明确开始所选屏的 5000K／15 秒测试，自动恢复后确认目标变化、其他屏幕不变及恢复正常。通过后在作息页开启该屏并保存。验证不自动开启，作用域或模式改变后需重新验证；这不是专业校色认证。
- 「屏幕与验证」始终显示全部屏幕及其状态，未验证、恢复冲突或断开也能查看说明。验证前若已有调色策略开启，会列明受影响屏幕；点击「关闭这些屏幕并继续验证」保存关闭状态并等待恢复，保留未保存的作息／色温，验证后需自行重新开启。恢复冲突先退出其他调色工具并恢复原色，再点击「重新检查原色」；重查不写设备，仅在当前颜色等于记录基线、身份和模式匹配时解除阻塞，否则保留记录并说明原因。
- 如果退出 f.lux 等软件后画面正常，但仍与旧原色不一致，或重新连接导致显示模式与旧记录不同，可点击“重新建立原色”。验证弹窗会列出待处理屏幕并提供“处理恢复记录”入口。程序唯一识别同一物理屏幕，并按当前模式只读检查颜色稳定性；检查成功后才显示观察确认项，失败则显示原因和重试入口。你确认所列屏幕画面正常后，程序备份旧记录并撤销旧资格，随后分别重新做 15 秒验证。此过程不会改变屏幕颜色或自动启用调色；备份位于数据根目录的 `color-temperature-archive-*.json`，请保留。旧原色可能本来就包含另一软件的调暖，不能仅靠反复重查解决。未解决其他屏幕的恢复记录时也暂不开始新验证，以免影响对其他屏幕是否被连带调色的判断。
- 已有实机证据仅为 DELL SE2723DS 的早先受控测试（用户确认本屏变暖、另一屏不变并恢复）；不直接导入为生产资格。新增客户端验证流程已通过模拟后端的写入/取消/恢复/冲突/模式变更测试，实际显示效果需在客户端观察；Q27P10 仍没有实机调色确认。
- 默认作息为 07:00 开始工作、18:00 开始休息、30 分钟过渡；工作保持原色，休息候选 4500K，首次选择工作“自定义色温”时的候选值为 5300K。旧配置原有时间、两组目标和实际开启状态会逐屏保留，不会自动打开未启用的屏幕。产品默认值不是医学阈值或仪器校准白点；原色来自接管前基线，不固定写入 6500K。新接入屏幕默认不参与；HDR、复制屏、远程及校色环境未经验证时不可接管。
- 配置分别位于 `health-reminder.json`（schema 1）和 `color-temperature.json`（schema 2，兼容读取旧 schema 1，首次成功保存时升级）；健康暂停截止在 `health-reminder-runtime.json`，色温基线和所有权在 `color-temperature-recovery.json`，设备验证在 `color-temperature-validation.json`。未知版本或损坏文件保留并显示错误。色温首次写硬件前，恢复记录必须刷盘且原子保存成功；异常退出不能保证立即恢复，下次启动先检查记录，冲突时不盲目覆盖。
- 降级前先关闭所有色温调节并确认恢复，备份设置、资格和恢复文件；旧客户端会拒绝 schema 2，需使用此前的 schema 1 配置备份，不能让旧版覆盖新设置或恢复日志。原有 `settings.json`、隐私图片及亮度恢复记录保持独立。

逐屏设置改版见 [010 设计](tasks/010-color-onboarding-design.md) 和 [实施验收](tasks/010-color-onboarding-plan.md)。模块基础范围和实际证据见 [007 设计](tasks/007-wellbeing-design.md)、[开发计划及验收](tasks/007-wellbeing-plan.md)；实机验证工具见 [ColorProbe](../tools/ColorProbe/README.md)。本模块尚未发布，不把读回或截图当作实际显示色温证明。

设置分区直接展示与连接变化后的原色处理修正见 [012 设计](tasks/012-settings-recovery-design.md) 和 [012 实施验收](tasks/012-settings-recovery-plan.md)。
