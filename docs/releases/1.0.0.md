# ScreenKeeper 1.0.0

Stable portable edition · Build 20260924.2.

## Download and run

Use ScreenKeeper-1.0.0-Portable-x64.zip on 64-bit Windows 10/11, or ScreenKeeper-1.0.0-Portable-x86.zip on 32-bit Windows 10. Windows 11 has no 32-bit OS edition.

Extract the complete ZIP, open the ScreenKeeper folder, and run ScreenKeeper.exe. The .NET runtime is included. Keep the accompanying DLLs and do not launch from inside a ZIP viewer.

Official website: https://screenkeeper.skyrrats.com/ . Click "Website ↗" at the top right of the application to open it in your default browser.

## Features

- Per-display idle blackout/dimming, keep-awake conditions and snoozing.
- Privacy curtain, show desktop or a specific app, with configurable quiet conditions and cross-display permissions.
- Work/break reminders with forest or mist backgrounds, snooze and skip actions.
- Per-display color schedules, original colors or custom temperatures, enabled after an observation test.
- Simplified Chinese/English, dark green/light fog themes and bulk display settings.

This build includes the x86 window API and cross-architecture app detection fixes. Both architectures use the same source snapshot. Settings and data formats remain compatible with the earlier 1.0.0 x64 package.

## Update and help

Exit from the tray and wait for brightness/color restoration before updating. Back up the entire Data folder. Extract the new package into a new folder and retain the Data settings from the same computer. Do not replace files while the application is running. Resolve outstanding recovery prompts first; do not delete recovery records to bypass protection.

Portable data is stored in Data\ScreenKeeper beside the application. Closing settings only hides the window. Share the original ZIP without personal data or logs. Bilingual instructions, 14 FAQs, and product/dependency licenses are included.

## Validation and release identity

The user has tried the x64 first version and the x86 build on their current 64-bit Windows computer, with no usage issues reported for x86. Native 32-bit Windows 10 has not been tested; WOW64 testing does not replace native x86 OS acceptance. Display controls depend on hardware and drivers; color control requires a per-display observation test.

The executable is unsigned and Windows may show an unknown-publisher warning. Disabling system protection is not an installation step. ScreenKeeper-1.0.0-SHA256SUMS.txt checks download integrity, not publisher authenticity.

The version is 1.0.0, build 20260924.2. VERSION.txt and the source manifest identify this build separately from earlier 1.0.0 packages. The historical screenkeeper-v1.0.0 tag is unchanged. Preparing these local artifacts does not mean they have been uploaded to a distribution platform.
