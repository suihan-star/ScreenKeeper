==================== 中文 · 快速上手 ====================

一、开始使用
选择版本：64 位 Windows 10／11 使用 x64 包；32 位 Windows 10 使用 x86 包。
x86 包也可在 64 位 Windows 上验证。Windows 11 没有 32 位系统版本。
实际已验证范围见包内发布说明或验证说明，不代表全部系统／显示器均已验收。
1. 将 ZIP 完整解压到有写入权限的位置，例如桌面或自己的应用文件夹。
2. 打开解压后的 ScreenKeeper 文件夹，双击 ScreenKeeper.exe。
3. 不需要安装 .NET，也不需要运行安装程序。请勿直接在压缩软件里启动。
4. 保留 EXE 旁的 DLL、配置和许可文件；不要只复制一个 EXE。
5. 若原有 ScreenKeeper 正在运行，先从右下角托盘选择“退出”，等待
   退出与恢复流程完成，再启动此便携版。关闭设置窗口不等于退出软件。

二、先选一个需要的功能
新配置默认不启用管理功能。建议逐项开启，确认效果后再设置其他项目。

屏幕休息：选择屏幕，开启功能，设置空闲时间、遮黑或调暗及保持唤醒条件。
隐私保护：选择屏幕，开启保护，设置等待时间与隐私幕、回到桌面或指定应用。
健康提醒：开启提醒，设置工作与休息时长，可先预览提醒外观。
色温调节：先到“屏幕与验证”逐屏完成观察验证，再到“作息与色温”开启
          该屏调节，设置工作和休息时段，然后保存。

修改设置后，请点击当前模块的“保存”。预览和编辑不等于保存成功。
屏幕休息与隐私保护分别开启、分别保存；两项共用当前选中的屏幕。
色温作息独立于健康提醒，“开始休息”不会自动切换色温时段。

三、日常操作
官网：窗口右上角「官网 ↗」在默认浏览器打开 https://screenkeeper.skyrrats.com/ 。
语言与主题：在窗口顶部切换中文／English，以及深绿／雾白绿主题。
回到设置：在系统托盘（含隐藏图标区）找到 ScreenKeeper，选择“打开设置”。
完全退出：从托盘选择“退出”；若提示尚有更改或恢复问题，按提示处理。
暂时不打扰：使用所选屏幕的“暂缓休息”或“暂缓保护”，无需反复改永久设置。
解除隐私幕：点击幕布上的“进入此屏幕”。普通鼠标经过或暂缓计时不会解除它。
离开电脑且需要阻止别人访问：使用 Windows 锁屏（Win+L）。

四、配置、升级与分享
便携版配置：程序文件夹下的 Data\ScreenKeeper，首次运行时自动创建。
便携版日志：Data\ScreenKeeper\Logs。
安装版／普通构建的数据路径不同，为 %APPDATA%\ScreenKeeper。

升级前，从托盘退出并确认亮度／原色恢复流程完成，备份整个 Data 文件夹。
保留自己的 Data，再更新程序文件；不要在程序运行时覆盖文件。
遇到恢复异常时保留记录，不通过删除配置、亮度或原色恢复文件来解除提示。
便携版不会自动读取安装版或 OLED Sleeper 的配置。
转发软件时使用原始 ZIP，不附带自己的 Data、日志、图片或验证记录。
换到另一台电脑时重新配置和验证屏幕，不复用旧电脑的恢复记录。

五、遇到问题
同目录的“常见问题-FAQ.txt”提供中英双语排查步骤，按 Q01—Q14 查找。
版本可查看 ScreenKeeper.exe 的“属性 → 详细信息”；成品包附有 VERSION.txt。
产品许可见 LICENSE；第三方组件声明与许可见包内相关文件。

==================== ENGLISH · QUICK START ====================

1. Get started
Choose x64 for 64-bit Windows 10/11, or x86 for 32-bit Windows 10.
The x86 build can also be tested on 64-bit Windows. Windows 11 has no
32-bit OS edition. See the included release or validation notes;
they do not imply acceptance on every OS version or display.
1) Extract the entire ZIP to a writable location, such as your Desktop or
   a folder you use for applications.
2) Open the extracted ScreenKeeper folder and double-click ScreenKeeper.exe.
3) No separate .NET installation or installer is required. Do not launch
   the EXE from inside a ZIP viewer.
4) Keep the DLLs, configuration and license files beside the EXE.
   Copying only the EXE is not enough.
5) If another copy of ScreenKeeper is running, choose "Exit" from its
   system tray menu and wait for shutdown and restoration to finish
   before starting this copy. Closing the settings window does not exit.

2. Start with one feature
Management features are off in a new configuration. Enable one at a time,
check the result, and then set up any other features you need.

Screen rest: Choose a display, enable the feature, and set the idle delay,
blackout or dimming action, and "Keep awake when" conditions.
Privacy protection: Choose a display, enable protection, and set the delay
and mode: Privacy curtain, Show desktop, or Specific app.
Break reminders: Enable reminders and set your work and break durations.
You can preview the appearance first.
Color temperature: Complete the observation test for each display under
"Displays & setup". Then enable that display under "Schedule & color",
set its work and rest periods, and save.

Click the current module's Save button after editing. A preview or an
edited value does not mean the setting has been saved.
Screen rest and Privacy protection have separate switches and saves.
They share the selected display.
Color schedules are separate from break reminders. Choosing "Start break"
does not automatically switch the color schedule to its rest period.

3. Everyday controls
Website: Click "Website ↗" at the top right to open
https://screenkeeper.skyrrats.com/ in your default browser.
Language and theme: Use the controls at the top of the settings window to
switch Chinese/English and the dark green/light fog themes.
Reopen settings: Find ScreenKeeper in the system tray, including its
hidden-icons area, and choose "Open settings".
Exit completely: Choose "Exit" in the tray menu. Follow any prompts about
unsaved edits or restoration.
Pause temporarily: Use "Snooze rest" or "Snooze privacy" for the selected
display instead of repeatedly changing your permanent settings.
Reveal a privacy curtain: Click "Enter this screen". Moving the pointer
over it or snoozing the timer does not dismiss an existing curtain.
Prevent access when leaving your computer: Lock Windows with Win+L.

4. Settings, updates and sharing
Portable settings: Data\ScreenKeeper inside the application folder.
This directory is created on first launch.
Portable logs: Data\ScreenKeeper\Logs.
Installed/regular builds use a different location: %APPDATA%\ScreenKeeper.

Before updating, exit from the tray and confirm that brightness/color
restoration has finished. Back up the entire Data folder.
Keep your Data folder when replacing the program files. Do not overwrite
files while ScreenKeeper is running.
Keep recovery records if restoration reports a problem. Do not delete
settings, brightness records or color recovery files to dismiss an error.
The portable edition does not automatically load settings from an
installed copy or from OLED Sleeper.
When sharing the app, send the original ZIP without your Data folder,
logs, images or display verification records.
On another computer, configure and verify displays again. Do not reuse
recovery records from the previous computer.

5. Need help?
Open "常见问题-FAQ.txt" in this folder. Both languages use Q01-Q14.
To check the version, open ScreenKeeper.exe Properties → Details.
The prepared package also includes VERSION.txt.
