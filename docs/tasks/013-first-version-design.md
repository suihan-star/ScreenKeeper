# 013 · 首版仓库整理与 Codeup 接入设计

日期：2026-09-23。关联 [实施计划](013-first-version-plan.md)。

## 目标与授权

用户确认首个版本的功能开发完成，要求整理项目并接入其 Codeup 仓库；随后明确授权整理、提交并推送。保留当前目录、已有功能成果、上游历史与 MIT 版权。此次为首版源码交付，不自动安装、启动客户端或创建线上发行版。

源码推送完成后，用户追加要求提供解压后可双击 EXE 使用的 ZIP 成品。本次追加交付为 1.0.0 的 Windows x64 自包含便携包，使用已确认标签的源码，不修改客户端功能、不清理已有 artifacts 或用户配置，不自动上传新产物或提交本轮文档。

## 范围

1. 根 README 以屏幕良伴 / ScreenKeeper 的首版功能、使用与开发入口为主；详细使用说明移入 docs，上游原说明保留文案留档（仅清理行尾空白），增加文档索引和首版变更记录。
2. 补齐本地配置、数据、证书和调试产物的忽略规则；保留设计源文件、必要图片和历史任务证据。对待提交文件做敏感信息和体积检查，不删除磁盘上的用户数据。
3. 为本产品建立独立版本前缀；用户已选择首版正式版本号 `1.0.0`，以 `screenkeeper-v1.0.0` 标签标记源码。历史上游标签保留在本地，不作为 ScreenKeeper 的发布标签。只推送 main 和此次确认的产品标签，不自动推送全部标签。
4. GitHub CI 面向 main，继承的自动发布脚本留档；保留手动构建入口，不触发发布。Codeup 流水线未配置时明确说明，不能把 GitHub 工作流等同于 Codeup 流水线。
5. 现有格式门禁发现的两个色温测试文件，以及提交检查发现的设计稿／文档多余空白，只作空白修正，不做全仓重构或改变业务逻辑。
6. origin 指向用户提供的 SSH 仓库，upstream 保持原项目。读取远程分支后确定普通快进／首次推送，遇到已有不兼容历史不强推、不覆盖。

## 验证与依赖

文档与版本整理 → 格式问题修正 → Release 构建／完整现有测试／格式检查 → 审阅待提交清单与敏感信息扫描 → 本地首版提交 → SSH 信任与身份验证 → 普通推送 main → 比较本地与远程提交。

SSH 必须使用可信的主机记录；不关闭主机校验、不暴露或复制私钥。企业专属域名首次连接若受审批阻止，完成本地工作后请求用户核对或明确信任展示的准确指纹，再继续推送；用户批准的首次信任不冒充官方指纹核验。私钥有口令保护时由用户在本机交互解锁，临时代理仅用于本次推送，收尾关闭，不改变系统服务或索取聊天中的密码。

真实显示器控制、系统主题切换、固定任务栏缓存及安装／卸载矩阵仍沿用各任务的已验证／待验证边界；完整单元测试不代替硬件验收。首版代码提交不等于已签名的正式安装发行。

## 回退

文件整理为可审阅的 Git 变更，上游 README／发布工作流保留副本。未改变用户运行数据或设备设置；需要撤回已推送整理时使用新的 revert 提交，不重写远程历史。版本前缀变更不改变配置 schema、安装 AppId 或程序互斥量。

## 便携 ZIP 追加交付

- 从 `screenkeeper-v1.0.0` 导出构建源码至新的 artifacts 子目录，明确使用 1.0.0 版本及对应提交身份；不覆盖当前源码或历史产物。
- 使用已有 `Portable=true`、`win-x64`、自包含发布和单文件压缩配置；保留发布生成的旁置 DLL，用户无需安装 .NET 或 Inno Setup。
- ZIP 内为一个 ScreenKeeper 文件夹，包含 EXE、运行依赖、中文快速说明、产品及随包依赖许可；用户设置仅在首次运行后写入本目录的 Data/ScreenKeeper。
- 核验发布结果、版本、依赖与许可、ZIP 解压一致性和 SHA256；不把包结构检查等同于无 .NET 的干净机器完整验收。无安全退出式检查入口时，不以 `--help` 启动真实显示器服务。
- 不使用现有 build.ps1 的整目录清理步骤，也不顺带修改安装器。回退只涉及本轮新产物，既有源码、运行配置和显示器状态不变。

## 双语帮助追加交付

用户要求使用说明为中英双语，并补充可能遇到的问题。快速说明与 FAQ 分开，统一维护于 docs/portable，采用可离线打开的 UTF-8 文本；两份文档各自按中文／英文分区，问题编号保持一致，文案以当前客户端和验证记录为依据。

范围包含启动、完整解压、托盘与退出、保存与升级、休息／隐私免打扰、指定应用回退、健康提醒、色温验证／恢复／试调、黑屏与反馈。不得把未复现故障写成确定归因，不指导删除恢复记录、强制退出恢复中的程序或关闭系统安全保护来处理问题。

build.ps1 仅增加便携包压缩前复制 docs/portable/*.txt 的步骤；不改变客户端、版本标签、安装器或原有清理行为。新帮助版 ZIP 使用另一 artifacts 目录，复用已核验的 1.0.0 程序与依赖，保留旧包。核验双语问题覆盖、文件引用、脚本语法、帮助文件逐字一致性、全部非帮助文件 SHA256 不变及新 ZIP 校验值。没有业务代码变更，不重跑硬件验收；本轮不自动提交、推送或发布。
