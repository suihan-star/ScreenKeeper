## 交互语义

- 点击显示器切换配置；所有未保存修改暂存在内存，切换不丢失。
- 管理开关控制该显示器的设置可编辑性，禁用时保留数值。
- 调暗时显示目标亮度，遮黑时显示“同时将亮度降至零”；无 DDC 时调暗与硬件亮度操作不可用，遮黑仍可选。
- 三个条件之间是“任一满足即保持唤醒”，明确标注；至少选一项，空闲时长为正整数。
- 保存针对全部显示器；保存失败保留更改；放弃更改恢复已保存值；底栏始终反馈是否有未保存修改。
- 原型覆盖加载、无显示器、读取失败、不支持亮度、保存失败、未保存关闭确认；关闭演示只显示“已收起到托盘”的模拟反馈。
- 主题和状态切换属于设计评审工具，本轮不默认承诺客户端新增主题选择功能。
- 语言入口位于窗口标题栏右侧，固定显示“语言 / Language”，仅提供“简体中文 / English”。这是用户新增的客户端设计要求，双主题均包含；切换即时更新窗口内文案、校验、时间单位和弹窗，不改变显示器数值、已保存配置或未保存状态。
- 原型语言仅保留于当前页面内存；刷新恢复中文。外围设计评审工具继续使用中文。实际客户端的本地化资源与语言偏好持久化在用户确认设计后实施，不能把本原型当作客户端已经支持双语。

## 验证、风险与回退

原型阶段验证 HTTP 加载、原型交互、两种主题及紧凑窗口截图、主要文字对比度。开发阶段的 WPF 渲染与测试结果见实施计划。无真实硬件操作，无医学护眼结论。

保存流程核对发现原文件服务吞掉写入失败，调用方会误标为已保存。本阶段将 `IMonitorSettingsFileService.SaveSettings` 改为返回 bool，失败由 UI 提示并保留草稿；同步更新调用方和测试。显示器 JSON schema 不变。时长输入同时防止 int 毫秒换算溢出；这是验证边界修复，不改变空闲行为算法。

本轮回退只涉及新增设计和文档，可逐文件审阅移除，不能回退用户已有改动。后续 WPF 应保持独立主题资源和原有功能接口，便于逐项回退。
