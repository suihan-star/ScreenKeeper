# 005 · 每屏隐私保护第一版

用户已授权按建议实施。关联 [005 计划](005-monitor-privacy-plan.md)。

## 范围与交互
- 每屏在“空闲时的操作”前增加隐私保护：关闭（旧配置默认）、隐私幕（推荐）、回到桌面；默认 30 秒，可设 1–86400 秒。
- 独立于现有屏幕休息计时，仅本屏实际鼠标操作及前台窗口所属屏幕的键盘输入刷新隐私计时；鼠标静止、其他屏幕输入不刷新。
- 增加“不休眠”，可仅启用隐私保护。现有遮黑/调暗及其唤醒条件继续适用。
- 如果遮黑/调暗的等待时间先到，执行前也先保护内容；用户主动暂缓期间尊重暂缓设置。连续输入在每次休眠后只请求一次亮度恢复，避免反复访问 DDC/CI。
- 鼠标/键盘活动可以唤亮屏幕，但不会自动解除隐私幕。使用明确的“继续使用此屏幕”按钮解除，按钮的鼠标抬起处理完毕后才移除窗口，避免点击穿透。
- 已保存并启用隐私的屏幕支持一键立即保护；选中屏幕可暂缓 15 分钟或恢复自动保护。暂缓不会自动移除已经显示的隐私幕。
- 回到桌面：先显示隐私幕，再只最小化完全位于目标屏幕的应用窗口；不使用 Win+D，不关闭应用，不自动还原窗口。跨屏窗口、无法最小化或验证失败时保留隐私幕，并显示原因。
- 第一版不启动/切换指定应用，不做密码认证，不替代 Windows 锁屏，不承诺阻挡系统安全桌面、系统级提示或应用崩溃后的显示。
- 隐私幕是普通置顶窗口，不是安全桌面；系统通知、任务切换及其他置顶程序仍可能显示在其上方。桌面模式成功后不会持续监视新窗口，应用自行弹窗仍可能展示内容。离开电脑且需要访问控制应使用 Win+L。

## 架构与生命周期
- 2026-09-17 桌面模式修正：`WS_MINIMIZEBOX` 只表明存在标准最小化按钮，不能作为程序化最小化的能力判断。对完全位于目标屏幕的窗口实际尝试非激活最小化，并复查可见窗口；同屏所有者窗口优先，仍可见的附属窗口再处理。保留跨屏拦截及失败时隐私幕兜底。
- 可见区域以所有物理显示器矩形的交集计算，屏幕外缘和屏幕间空白不算跨屏；窗口实际覆盖另一显示器时仍拦截。发出最小化请求前再次核对位置。若所有者的附属窗口位于另一屏，也不最小化该所有者，以免连带影响其他屏幕。
- 最大化窗口按 `IsZoomed`、`GetDpiForWindow` 和 `GetSystemMetricsForDpi` 的窗口边框尺寸校正规范范围；只有落在所属显示器加系统边框范围内才裁剪，普通窗口和真正跨屏的自定义最大化窗口不放宽。
- 异步最小化复查时间上限从 500 ms 延长为 1500 ms；明确解除、配置变化、停止或重新保护会取消过期操作，防止解除后继续最小化窗口。
- 桌面窗口原生访问通过可替换接口隔离，回归测试覆盖整个枚举、请求、复查流程；失败日志仅记录分类和数量，不记录标题、进程路径或用户内容。
- 新增 Features/MonitorPrivacy：可测试的单屏计时状态、输入活动来源、桌面切换服务、隐私协调服务、独立隐私幕宿主。
- 原生钩子只收集输入时间与屏幕位置/归属，不记录按键值、窗口标题或用户内容；调用在 UI 消息线程，卸载时解除钩子。
- 隐私幕宿主与现有遮黑服务共享“休眠显示”状态：睡眠时隐私幕显示黑色，唤醒时显示静绿解除页面；正常恢复命令不得关闭隐私幕。
- 同一屏幕重新配置或显示拓扑变化时保留已显示的隐私幕并重新定位；不让设置保存顺带解除保护。关闭保护的设置是明确用户操作，可移除该屏幕的隐私幕。断开显示器清理其窗口。
- 新设置为向后兼容可选字段，旧文件默认关闭隐私；读取异常值时使用安全的计时默认值。保存/放弃/草稿恢复/中英文均覆盖新字段。
- 隐私幕显示失败按屏报告，不误报为已保护；下一次超时重试。桌面操作使用异步最小化并复查可见窗口，无法确认成功就保留遮挡；并发保存设置使过期的桌面操作结果失效。

## 验证与回退
- 模拟输入/时钟/窗口宿主测试：其他屏输入不重置、静止鼠标、超时、暂缓、手动保护、输入不解除隐私幕、桌面失败保留遮挡、设置重载和显示器移除。
- 桌面规划测试跨屏/不可最小化/无窗口；设置测试旧 JSON、往返保存、无效时长、草稿与语言切换。
- WPF 离线渲染中英配置、700×500 滚动、隐私幕/休眠/失败状态，核对绑定。构建、现有测试和格式检查后打包本地便携版，不自动运行硬件管理或最小化用户窗口。
- 回退可在界面关闭隐私或恢复本轮代码；已有亮度记录及用户数据不删除。旧版程序不支持隐私字段，旧版保存会丢失新字段，降级前保留 settings.json 备份。
