# 016 · 客户端官网入口设计

日期：2026-09-24。关联 [开发计划](016-official-website-plan.md)。用户提供官网 https://screenkeeper.skyrrats.com/ 并要求在软件中可以打开。

- 在主窗口右上角、主题选择器左侧加入常驻「官网 ↗」按钮，英文「Website ↗」。使用已有双主题控件与实时本地化，保留 700×500 最小窗口和 WindowChrome 命中行为。
- 官网 HTTPS 常量集中于 ProductIdentity；只响应用户点击，以 UseShellExecute=true 交给系统默认浏览器。不自动联网、不内嵌浏览器、不传用户数据或草稿。
- 系统无法打开时用现有 AppDialog 显示双语提示及完整网址，不中断设置编辑。
- 沿用已授权的 1.0.0 正式版，重新冻结源码、构建两个便携包，构建标识 20260924.2。记录新源码／ZIP 校验值，保留 015 旧成品及原 Git 标签；不自动提交、推送或上传。
- 先编译并运行现有布局／本地化验证，检查深浅主题、中英文、正常／最小尺寸截图，再核验重新打包后的实际版本、依赖、自包含加载及完整性。不变更业务、存储 schema 或硬件行为。
- 回退只撤销本入口代码并使用保留的旧 ZIP；不覆盖运行客户端、用户 Data 或已有未提交变更。
