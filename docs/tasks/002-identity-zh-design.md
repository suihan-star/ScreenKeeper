# 第一阶段：独立身份与核心中文化设计

日期：2026-09-16

## 已确认范围

用户确认按“独立身份＋核心中文化”推进，不继承 OLED Sleeper 配置；在当前目录开发，保留初始化文档的未提交变更。不提交、推送或发布。

目标是提供可本地试用的多屏管家 ScreenKeeper，保留现有遮黑、DDC/CI 调暗、空闲检测和唤醒行为，沿用现有 WPF 布局。解决方案、源码目录和命名空间继续沿用上游名称，避免无关重构。

## 身份与数据隔离

- 产品显示名称：多屏管家 ScreenKeeper；可执行文件/程序集：ScreenKeeper。
- 安装版数据目录：%APPDATA%\ScreenKeeper；日志仍位于该目录下 Logs。
- 便携版数据目录：程序旁 Data\ScreenKeeper；即使目录中存在原版 Data\settings.json，也不读取或修改它。
- 互斥量：ScreenKeeper-Mutex；窗口唤起事件：ScreenKeeper-ShowWindow；HKCU Run 启动项：ScreenKeeper。
- 安装 AppId 使用新 GUID，安装目录与快捷方式改为 ScreenKeeper；安装、卸载只管理本产品启动项。
- 不导入、复制或删除原版配置。移除继承的安装时清空配置规则，使本产品重装保留自己的配置及亮度恢复记录。
- 本地构建产物改用 ScreenKeeper 名称；沿用 MinVer 的历史版本推导，仅供开发试用，正式版本策略与自动发布迁移留待后续。

隔离不保证两个应用同时控制同一显示器时不会争用；硬件验收时逐个运行。回退使用此前版本/单独输出目录，不重置现有工作区，不删除任何用户数据。

## 核心中文界面

覆盖窗口标题、托盘菜单、显示器编号/主屏标记、配置字段、时间单位、工具提示、校验错误、未保存确认及启动存储失败提示。使用支持中文的字体。枚举值、JSON 字段和硬件标识保持不变，时间单位只翻译显示文本。

检查正常配置、未选择/无显示器、加载、错误、最小窗口与高 DPI 布局。必要时仅做防裁切和状态提示调整。系统 MessageBox 按钮及底层异常详情可能随 Windows 语言显示。

渲染核验后的布局调整：显示器布局为标题与刷新按钮预留独立空间，显示器标签只缩小不放大；主区域按比例分配，配置区可纵向滚动，保存/放弃按钮固定在底部。补充无显示器与加载失败提示，失败后可重新检测。修复原版调暗按钮指向不存在的 DimBehaviorTooltip 的绑定，改用现有行为说明。

## 边界

本阶段不做新图标设计、安装向导完整汉化、多语言切换、UI 重设计、新屏幕控制模式、自有远程配置、CI/自动发布迁移或正式发行。保留上游版权，随本地产物携带根 LICENSE；完整第三方许可清单仍是正式发布前置任务。

## 实施依赖与验证

先统一运行时身份及数据路径，再同步安装/打包引用，随后完成中文显示与必要布局调整，最后回归测试与本地试用产物。复用现有测试，对数据隔离、时间单位绑定和受影响行为增加必要回归验证。

执行 restore、Release build、test、format、diff --check，并尝试便携输出。优先通过不连接真实显示器的 WPF 渲染核验中文布局；真实 DDC/CI、热插拔、托盘、开机启动及安装卸载共存需要目标桌面人工验收。环境缺少 Inno Setup 或原生桌面操作能力时明确记录，不声称已验证。

## 本机 Inno Setup 补齐（2026-09-16）

用户明确授权直接安装 Inno Setup。选择与现有 build.ps1 搜索路径及 installer 脚本匹配的官方 Inno Setup 6 稳定版（6.7.3），从官方公布的 GitHub 下载链接获取，执行前核验数字签名及发布方、SHA-256。采用静默安装，不启动编辑器，不变更关联文件或额外创建桌面快捷方式。安装完成核验 ISCC，并构建本地安装包；不安装 ScreenKeeper 本身，不提交、推送或发布。回退通过 Windows 官方卸载入口处理，不手动删除共享工具目录。
