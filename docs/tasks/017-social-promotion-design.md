关联计划：[017-social-promotion-plan.md](017-social-promotion-plan.md)。

## 目标与范围

根据用户对首稿的反馈，将功能介绍改为面向久坐办公用户的陪伴叙事，明确 Windows 单屏与多屏均适用，强调隐私保护、休息提醒、屏幕休息与色温调节。交付可复制的 X / 小红书中文文案、一张 X 横版图和三张小红书竖图；第二轮进一步交付四模块的 GIF / MP4 连续演示。本任务只创建本地推广素材，不发布到平台，不修改应用或官网代码。

## 内容与视觉

- X：以“消息催你回，谁提醒你歇一会儿？”引出开发者作品，正文短，直接给官网入口；目标为普通短帖篇幅。
- 小红书：封面提出“你照顾工作，谁照顾你？”，内页分别表达隐私与休息，正文使用办公情境、可理解收益和简单的首次试用动作。
- 图像：imagegen 生成完整海报；X 目标 16:9，小红书目标 3:4。暖米白、深山林绿、雾绿和有生活感的双屏桌面，醒目的简体中文标题。
- 场景图标注“场景示意”，不冒充软件实机截图。隐私图说明不替代系统锁屏。
- 不宣称医学效果、绝对保密、硬件普遍兼容、免费或开源等未经确认的推广卖点；不虚构用户量、口碑、亲历故事。

## 第二轮：单屏适用与四模块动态图

- 用户确认主张为“单屏多屏，皆由你心定”。新版使用 v2/ 子目录，保留首轮海报、文案、压缩包与验证结论。同步更新宣传文字，不将“多屏”作为使用前提。
- imagegen 负责四张海报的定向编辑，封面与健康海报加入单屏场景。动态图使用 baoyu-design 的 animations-v3 时间轴，参考相邻只读 Screen-Keeper-web/src/components 的四个功能演示及官网语义色板；每段以单屏演示主体，画面明确为效果示意。
- 屏幕休息：正常工作 → 示例空闲等待 → 遮黑 → 满足选定活动条件 → 恢复内容。调暗能力用短说明标明需要设备支持，不将遮黑演示称为物理断电。
- 隐私保护：示例内容 → 等待 → 先不透明遮挡，再显示山林 → 鼠标经过仍保护 → 明确点击“进入此屏幕” → 恢复内容。持续说明隐私幕不替代系统锁屏。
- 健康提醒：工作 → 轻提醒卡片 → 点击“开始休息” → 全屏山林与示例倒计时 → 提前结束回到工作；保留稍后、跳过操作名称，不宣传治疗效果。
- 色温调节：保持原色 → 作息暖色示意 → 原色对比 → 回到原色。原色不标为固定 6500K，标明需先完成屏幕验证，动画色调不是硬件实测或校色结果。
- 每段目标 18 秒循环，固定 3:4 画幅，MP4 为 900×1200，GIF 为 540×720。等待时间被压缩，真实计时与硬件不受影响。交付可播放预览页、源码、导出文件、关键帧与校验清单。
- 验证：海报逐张检查；连续播放与场景边界前后截帧；四模块关键状态和解除条件；GIF 帧数/时长与 MP4 解码；文件校验及本地预览。未验证平台分发或实际转化。
- 回退：保留 v1 产物，本轮只新增 v2 资产并更新本任务记录和根 AGENTS.md 的单屏适用长期产品事实。
