# 010 色温设置交互优化设计（已确认，客户端实施）

延续静绿／雾白绿、现有窗口和中文／英文。用户已确认进入开发；本轮实现 WPF 页面、每屏配置和调度，保留原验证及恢复门禁。前序依据：007 色温能力、008 全应用布局、当前 ColorSettingsView 与 ColorSettingsViewModel。入口沿用 color-v5.html，保留 v4。

## 用户确认的方向与本轮修订

2026-09-20 用户明确取消三步首用流程，保留「作息与色温」「屏幕与验证」两个长期使用的功能页签。本轮覆盖此前三步方案，不再保留开始／下一步／完成等首用导航。

「作息与色温」内以屏幕选择卡片而非第三层功能页签展示当前已验证可用的屏幕，卡片区分选中、开启、关闭和未保存状态；窄窗口或超过三屏使用带状态的下拉框。选择屏幕不启用、不试调、不保存。

选中屏幕后，显示「开启此屏幕色温调节」开关。关闭时仅显示说明，工作／休息配置隐藏，原参数保留；打开后展开该屏的工作与休息时间、原色／色温、时间轴。开关和参数均为草稿，保存后生效；上方明确展示该屏已保存状态。切换屏幕保留各自草稿。

试调直接针对当前屏幕，免去第二次选屏；明确开始后才联动滑杆，停止输入 15 秒后恢复该屏已保存策略。切屏、切主页签、保存、放弃、隐藏窗口或离开模块结束试调，不丢草稿。更多选项保留手动模式、过渡时长和临时使用原色。

「屏幕与验证」列出所有屏幕，以已验证／尚未验证／原色需确认／HDR／断开区分。已验证可直接进入该屏设置；验证后不自动启用，在此页提示并提供「设置这块屏幕」入口。没有可用屏幕时，作息页提供空状态及转至验证入口，不强制流程引导。

## 文案与工作色温交互修订

按用户进一步反馈，开关标题使用「开启此屏幕色温调节」。工作时采用明确的「保持原色／自定义色温」双选项，替代隐藏自定义能力的复选框；原色模式显示简短说明，自定义模式展示滑杆及 K 值。切换模式保留先前自定义数值，只改变草稿并结束正在进行的试调。

「照顾屏幕，也照顾自己」移到标题栏软件名称后方，删除侧栏底部重复文案；沿用中英文，最小窗口中保持主题／语言和窗口按钮可用。已落实于 WPF 标题栏，窄窗中口号可省略显示并保留完整提示。

## 每屏独立设置是新增能力

此前客户端仅有共享作息、色温及总开关，ParticipatingScreens 保存参与标记。本次按确认方案实现每屏独立配置及调度，采用下述 schema 2 迁移策略；保留原有验证、所有权与恢复安全边界。

保存范围为色温模块所有屏幕草稿；固定保存栏显示修改屏幕数量，失败保留全部草稿。不可用屏幕的既有设置在验证页可关闭，参数保留；其恢复与硬件门禁不因界面调整而放宽。原色来自接管前基线，不等同于 6500 K。

## 验证与异常处理

保留用户选择目标、5000 K／15 秒观察及三项实际观察确认。确认通过仅获得资格，不自动开启。单独验证弹窗属于设备验证过程，不是色温设置的强制向导。

为保持独立性观察，开始验证前若任一已保存屏幕策略开启，明确列出受影响屏幕并提供「关闭这些屏幕并继续验证」。该动作只持久化这些屏幕关闭状态并等待恢复，保留所有未保存的作息／色温参数，不静默恢复开启。该交互等待真实服务完成恢复；失败显示原因，设备验证仍受服务门禁约束。

原色冲突保留只读重查、列出全部受影响屏幕、用户确认正常画面、耐久归档／撤销旧资格／更新记录及重新验证。不能把未知颜色直接接纳为原色，不能自动调色。HDR／断开显示原因和下一步。

## 范围与验证

实施 WPF 色温页、ViewModel、普通设置存储兼容、逐屏调度、验证关闭动作、中英文和标题栏口号；不调整健康／隐私功能或硬件后端。测试覆盖每屏草稿、开关、保存／放弃、资格门禁、空状态、异常与试调取消，并核验双主题、双语、700×500 及多屏下拉。硬件测试仅使用模拟后端，不把测试或截图视作实机兼容证明。

## 客户端实现与兼容决策

- 色温普通设置升级为 schema 2，新增按 HardwareId 保存的 ScreenProfiles（开关、模式、工作／休息时间、两组目标、原色选择、过渡）。旧 schema 1 只读加载，按旧 Enabled 与 ParticipatingScreens 的交集迁入开启状态；旧参数逐屏保留。首次成功保存才写 schema 2，新屏幕默认关闭。
- 色温存储显式接受 schema 1／2，其他模块仍只接受自身原版本；未知版本主文件阻止备份覆盖。旧客户端只认 schema 1，会拒绝 schema 2，不能误读为共享作息。恢复日志、资格、健康和显示器文件不改版本。
- 串行服务按每屏的已保存配置分别计算日程；预览取消恢复该屏策略，临时原色截止基于该屏下一工作开始。验证／重新建立原色仍要求所有已保存调节关闭；界面提供显式关闭并保存动作，保留其他草稿，并等待服务完成恢复，失败不继续验证。
- 界面按屏幕保存原始输入草稿，切屏、能力刷新、语言和主题变化不覆盖；保存范围为所有屏幕草稿。作息页仅列出已验证可用屏幕，其他屏幕参数保留并可在验证页关闭。
- 回滚：先在新版关闭所有屏幕调节并确认恢复，备份 schema 2 设置及恢复／资格文件，再恢复此前 schema 1 备份或继续使用新版；不能让旧版覆盖新配置或恢复日志。开发不自动修改用户真实配置、不操作真实 Gamma。
