# 屏幕良伴 · 首轮社交推广素材

本套以“给久坐、多屏办公的人一个体贴的桌面搭子”为核心，文案使用开发者本人分享作品的口吻。

## 发布文件

- copy-x.txt：X 可直接复制的正文；配 x-poster.png。
- copy-xiaohongshu.txt：小红书标题、正文与话题；图片顺序为 xhs-01-cover.png、xhs-02-privacy.png、xhs-03-break.png。
- generation-prompts.json：四张海报的完整生成提示词。
- screenkeeper-social-launch.zip：交付文件压缩包。

## 图片性质

图片使用 OpenAI imagegen 生成，属于推广场景示意，不是客户端实机截图。只有虚构的工作内容；隐私幕上的“进入此屏幕”与健康提醒的三个操作名称对应实际产品能力。文件不含用户桌面、聊天记录或其他私人信息。

## 核对与使用

X 文案按 [官方字符计数](https://docs.x.com/fundamentals/counting-characters) 核算为 211，不含文件末尾换行；照片附件不占正文字符。小红书采用三张连续竖图，引入情绪共鸣，再解释隐私与休息两个场景。实际图片信息以 manifest.json 为准。

下载地址使用 https://screenkeeper.skyrrats.com/ 。文案未声明免费、绝对隐私或医学效果。初次使用功能需要在客户端开启并保存。没有代发帖子，也没有测试真实发布效果。
